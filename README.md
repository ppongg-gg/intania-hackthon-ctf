# intania-hackthon-ctf

## 🧠 Mission: Bits Battle — CTF Challenge Design

## 📌 Project Summary

Designed and developed **Mission: Bits Battle**, a multidisciplinary **Capture The Flag (CTF)** challenge consisting of 8 problems that evaluate participants across **computer science, data science, and software engineering domains**.

---

## 🎯 Design Objectives

- Create challenges that simulate **real-world technical problem solving**
- Encourage **cross-domain thinking** (web, data, systems)
- Evaluate both **analytical reasoning** and **tool proficiency**
- Balance accessibility with depth through **progressive difficulty**

---

## 🧩 Challenge Design Breakdown

| Domain | Problems | Key Concepts |
|------|--------|-------------|
| Image Processing | 1, 7 | Pixel operations, LSB steganography |
| Signal Processing | 2 | Spectrogram analysis |
| Web Development | 3, 5 | DevTools inspection, HTTP methods |
| Data Structures | 4 | Array reshaping, image representation |
| Cryptography | 6 | XOR decryption, brute-force |
| Data Science | 8 | PCA, dimensionality reduction |

---

## 🧠 Skills & Knowledge Assessed

### Analytical Thinking
- Decomposing ambiguous problems
- Identifying hidden patterns in transformed data
- Selecting appropriate tools under time constraints

### Data Representation Awareness
- Interpreting images, audio, and arrays as structured data
- Converting between different data modalities (audio → image, array → image)

### Systems & Web Understanding
- Inspecting frontend code (HTML/CSS/JS)
- Understanding HTTP request behavior and client-server interaction

### Low-Level Reasoning
- Working with binary data and bitwise operations
- Understanding encoding and reversible transformations (XOR, LSB)

### Data Science Intuition
- Recognizing high-dimensional structures
- Applying dimensionality reduction for visualization and insight extraction

## 🛠️ Technical Components

- Python (NumPy, visualization, scripting)
- Web stack (HTML, CSS, JavaScript, HTTP)
- Binary file processing
